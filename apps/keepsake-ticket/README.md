# Keepsake Ticket

Turn one real travel or everyday photo into a personal illustrated ticket through three tactile gestures.

- Package: `@eazo/keepsake-ticket`
- Port: `5111`
- Product language: `en-US`
- Primary target: latest formal iPhone/iOS
- State: `BUILDING` — first visual preview, awaiting Owner review

## Run

```bash
pnpm --filter @eazo/keepsake-ticket dev
pnpm exec playwright test --project=keepsake-ticket-webkit-mobile
```
